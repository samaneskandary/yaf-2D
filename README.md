# ساکر استارز ⚽

فوتبالِ دو بُعدیِ آفلاین، PWA، فارسی و راست‌به‌چپ، حالتِ پرتره.
همهٔ فایل‌های بازی داخل پوشهٔ `www/` هستند و مسیرها نسبی‌اند تا تبدیل به اپ نیتیوِ اندروید با حداقلِ زحمت ممکن باشد.

---

## گذاشتنِ موسیقیِ پس‌زمینه (صفحهٔ اول)

فقط کافی است **یک فایلِ موسیقی** را داخلِ `www/` بگذاری و نامش را یکی از این‌ها بگذاری:

```
www/menu-music.mp3      (یا)
www/menu-music.ogg
www/menu-music.m4a
www/menu-music.wav
```

همان فایل به‌صورتِ خودکار در منوی صفحهٔ اول پخش می‌شود (لوپ).
کاربر چیزی انتخاب نمی‌کند؛ فقط یک دکمهٔ کوچکِ روشن/خاموش برای قطعِ صدا هست.

> نکته: مرورگرها تا پیش از اولین لمسِ کاربر اجازهٔ پخشِ خودکار نمی‌دهند؛ بازی این را مدیریت می‌کند و با اولین تپ، موسیقی شروع می‌شود. در اپِ اندروید این محدودیت معمولاً وجود ندارد.

---

## اجرای سریع (تست در مرورگر)

چون از سرویس‌ورکر استفاده می‌شود، فایل‌ها را روی یک سرورِ ساده اجرا کن (نه `file://`):

```
cd www
python3 -m http.server 8080
# سپس باز کن: http://localhost:8080
```

---

## ساختِ APK با Capacitor (کم‌ترین زحمت)

پیش‌نیاز: Node.js و Android Studio.

```
# در ریشهٔ پروژه (کنارِ capacitor.config.json)
npm install
npx cap init "ساکر استارز" com.soccerstars.app --web-dir=www   # اگر قبلاً init نشده
npm run android:add        # افزودنِ پلتفرمِ اندروید (cap add android)
npm run android:sync       # کپیِ www داخلِ پروژهٔ اندروید (cap sync)
npm run android:open       # باز کردن در Android Studio (cap open android)
```

در Android Studio از منوی **Build → Build Bundle(s)/APK(s) → Build APK(s)** خروجیِ APK بگیر.
هر بار که فایل‌های داخلِ `www/` را تغییر دادی، دوباره `npm run android:sync` بزن.

### آیکن و نام
- آیکن‌ها در `www/icon-192.png`، `www/icon-512.png` و `www/icon-maskable-512.png` هستند (برای PWA).
- برای آیکنِ نیتیوِ اندروید از Android Studio: `Res → New → Image Asset` استفاده کن.
- نام و `appId` در `capacitor.config.json` تنظیم شده‌اند.

---

## گزینهٔ جایگزین (بدون Node): PWABuilder
چون پروژه یک PWA کامل است (manifest + service worker)، می‌توانی پوشهٔ `www/` را روی یک هاست بگذاری و در سایتِ **pwabuilder.com** آدرس را بدهی تا بستهٔ اندروید (TWA) بسازد.

---

## دربارهٔ فونت
فونتِ Vazirmatn از Google Fonts بارگذاری می‌شود؛ در حالتِ کاملاً آفلاین بار نمی‌شود و فونتِ پیش‌فرضِ سیستم جایگزین می‌شود (بدونِ مشکلِ عملکردی). اگر فونتِ آفلاین خواستی، فایلِ woff2 را در `www/` بگذار و در `styles.css` با `@font-face` معرفی کن.

## این نسخه شاملِ این هشت تغییر است
1. توپِ جهنده با سایهٔ طبیعی کنارِ دکمهٔ «بزن بریم» (سایه هنگامِ پایین‌آمدنِ توپ بزرگ/تیره و هنگامِ بالا رفتن کوچک/کم‌رنگ می‌شود، لوپ مثلِ جامِ بالای منو).
2. پخشِ خودکارِ یک فایلِ موسیقیِ پس‌زمینه در منو (فرمت‌های متعارف).
3. نورپردازیِ دو منبعه: دو منبعِ نورِ فرضی در چپ و راستِ زمین، وسطِ طول؛ کنتراستِ کم؛ سایهٔ نرم؛ سایهٔ مهره‌ها و توپ مطابقِ همین دو نور.
4. ده کشور برای انتخاب (ترکیه، آلمان، ایتالیا، ایران، مراکش، پاکستان، سنگال، جامائیکا، آفریقای جنوبی، برزیل) — بدونِ کشورهای دارایِ محدودیتِ انتشار.
5. تورِ دروازه پررنگ‌تر و واضح‌تر (بدونِ افزایشِ ضخامتِ خطوط).
6. برفکِ ریزِ تصادفی و الگوی طبیعی‌ترِ زمین.
7. دو میله‌ی اوریبِ بالای دروازه به‌صورتِ خطِ کاملاً صاف، هم‌ضخامتِ تیرهای جلو و به رنگِ خاکستریِ روشن.
8. تایمرِ ۲۰ ثانیه‌ایِ هر نوبتِ بازیکن؛ با پایانِ زمان، نوبت به حریف می‌رسد و پیامِ «زمان تمام شد! ⏱️» نمایش داده می‌شود (شمارشِ معکوس کنارِ نشانگرِ نوبت).

> دربارهٔ مورد ۷: «دو میله‌ی اوریب» را همان دو میله‌ی شیب‌دارِ بالای دروازه (از قابِ جلو تا قابِ عقب) در نظر گرفتم که با گرادیانِ قبلی پله‌پله دیده می‌شد؛ حالا خطِ صافِ خاکستریِ روشن با ضخامتِ تیرهای جلو هستند. اگر منظورت خطوطِ شیب‌دارِ کفِ دروازه بود، بگو تا همان‌ها را عوض کنم.
